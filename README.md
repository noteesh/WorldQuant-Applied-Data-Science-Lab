# WorldQuant Applied Data Science Lab
<br>

The Applied Data Science Lab at WorldQuant University was an incredible 16-week journey that gave me hands-on experience tackling real-world data challenges. This immersive online program was all about building practical skills—everything from data wrangling and analysis to model-building and clear communication.

Throughout the program, I worked on eight exciting projects, each designed to reinforce key data science concepts. These projects pushed me to apply what I learned in meaningful ways, deepening my understanding and sharpening my problem-solving skills.
<br>

### :trophy: [Completion Badge](https://www.credly.com/badges/41814e62-a7e7-4502-b5e5-e7b1bbec8a98/linked_in_profile)

<br>

![](https://img.shields.io/badge/Project%201-Housing%20in%20Mexico-eb3470?style=for-the-badge)
> Analyzed a dataset of 21,000 real estate properties in Mexico to determine whether prices are driven more by property size or location. I imported and cleaned the data, created visualizations, and explored correlations between these factors, gaining valuable insights into real estate pricing trends.
<br>

![](https://img.shields.io/badge/Project%202-Apartment%20Sales%20in%20Buenos%20Aires-orange?style=for-the-badge)
> Built a linear regression model to predict apartment prices in Buenos Aires, Argentina. I created a data pipeline to handle missing values and encode categorical features, improving model performance by reducing overfitting. This project strengthened my skills in predictive modeling, machine learning with scikit-learn, and building interactive dashboards.
<br>

![](https://img.shields.io/badge/Project%203-Air%20Quality%20in%20Nairobi-990098?style=for-the-badge)
> Built an ARMA time-series model to forecast particulate matter levels in Kenya using air quality data from openAfrica. I extracted data from a MongoDB database with pymongo, prepared it for analysis, and fine-tuned the model through hyperparameter tuning. This project deepened my understanding of time series modeling, with applications in public health, finance, and NLP.
<br>

![](https://img.shields.io/badge/Project%204-Earthquake%20Damage%20in%20Nepal-fcba03?style=for-the-badge)
> Built logistic regression and decision tree models to predict building damage from the 2015 Nepal earthquake using data from Open Data Nepal. I extracted relevant data from an SQLite database, analyzed potential biases in the dataset, and explored ethical considerations in model building. This project enhanced my skills in classification modeling and database querying.
<br>

![](https://img.shields.io/badge/Project%205-Bankruptcy%20in%20Poland-fc4903?style=for-the-badge)
> Built random forest and gradient boosting models to predict company bankruptcy using data from Polish economists. I navigated the Linux command line, handled data imbalance with resampling techniques, and evaluated model performance using precision and recall. This project strengthened my skills in classification modeling, data preprocessing, and performance evaluation.
<br>

![](https://img.shields.io/badge/Project%206-Customer%20Segmentation%20in%20the%20US-f22ce2?style=for-the-badge)
> Used data from the 2019 Survey of Consumer Finances to identify households struggling with credit access and clustered them into subgroups using a k-means model. I applied PCA for dimensionality reduction and built an interactive dashboard with Plotly Dash. This project deepened my skills in unsupervised learning, customer segmentation, and data visualization.
<br>

![](https://img.shields.io/badge/Project%207-A/B%20Testing%20at%20worldquant%20University-green?style=for-the-badge)
> Conducted an A/B test to assess the impact of email communication on program enrollment at WQU. I designed and analyzed an experiment using a chi-square test, developed custom Python classes for an ETL process, and built an interactive web application using a three-tiered design pattern. This project strengthened my skills in experimental design, statistical analysis, and web app development.
<br>

![](https://img.shields.io/badge/Project%208-volatility/market%20forecasting%20in%20india-54c7b9?style=for-the-badge)
> Built a GARCH time series model to forecast asset volatility on the Bombay Stock Exchange. I retrieved stock data via an API, cleaned and stored it in a SQLite database, and created my own API to serve model predictions. This project reinforced my skills in financial modeling, time series forecasting, and deploying machine learning models through web APIs.
